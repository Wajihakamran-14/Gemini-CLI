This repository contains the Elegance Jewellry website files.

## Elegance Jewels Website

This is a static website for "Elegance Jewels," a fictional jewelry brand. The website showcases a collection of exquisite jewelry, provides information about the brand, and allows users to contact them.

### Features:
- **Home Section:** Introduces the brand with a captivating hero image and a call to action.
- **About Us Section:** Details the brand's passion for craftsmanship and timeless design.
- **Products Section:** Displays a grid of featured jewelry products with images, names, and prices.
- **Collection Section:** A gallery showcasing various jewelry pieces.
- **Contact Section:** A form for users to send messages to Elegance Jewels.
- **Responsive Design:** The website is designed to be responsive, adapting to different screen sizes.
- **Smooth Scrolling:** Implemented for navigation links to enhance user experience.

### Technologies Used:
- HTML5
- CSS3
- JavaScript
